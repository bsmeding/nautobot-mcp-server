Nautobot MCP Server

This app is installed. Version {{ version }}. It is listed under Apps → Installed Apps. This page is Apps → MCP Server → MCP Server Status (/plugins/mcp-server/).

Installing the app does not start the MCP server. Run nautobot-mcp next to Nautobot, or let each person run it locally with their own NAUTOBOT_URL and NAUTOBOT_TOKEN. Claude and Cursor talk to that process, not to this page.

Client setup

Local (Claude Desktop, Cursor). Nothing else is installed in Nautobot. On the client machine, uv is enough; uvx runs nautobot-mcp. Each person puts their own token in their MCP config: 

{
  "mcpServers": {
    "nautobot": {
      "command": "uvx",
      "args": ["nautobot-mcp"],
      "env": {
        "NAUTOBOT_URL": "https://nautobot.example.com",
        "NAUTOBOT_TOKEN": "YOUR_PERSONAL_API_TOKEN"
      }
    }
  }
}

Shared server on this Nautobot host. Start nautobot-mcp --transport streamable-http. Set require_client_token so each client sends X-Nautobot-Token. One nautobot_token in PLUGINS_CONFIG would record every person as that user.
